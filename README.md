# IRAID

IRAID is a Next.js App Router site with a shared responsive shell, optimized static assets, accessible galleries, and client-side navigation.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Routes include Home, About, Programmes, Gallery, Our team, Stories, and Contact. The original media library lives in `public/assets` and is served through Next.js.

The previous static HTML/CSS site is kept in `old/legacy-site`; it is not part of the live app.

Original reference documents and source media are kept in `old/source-materials`.
